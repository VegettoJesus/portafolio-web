Sistema de Egresos
Laravel 8 · SQL Server · Bootstrap 5 · jQuery
El Reto

El área administrativa y financiera del instituto contaba con un sistema antiguo que funcionaba, pero presentaba graves fallas de seguridad y una experiencia de usuario muy pobre:

  • Seguridad crítica: El login era sumamente básico y las contraseñas en la base de datos se guardaban en texto plano (visibles para cualquiera con acceso al servidor).
  • Reportes visualmente pobres: Los reportes existían, pero se mostraban como HTML crudo sin CSS (tablas amontonadas, difíciles de leer). Además, no había forma de exportarlos a un documento formal.
  • Mala visualización de datos: Aunque el sistema ya hacía cálculos financieros, la información se mostraba de forma desordenada, dificultando la navegación y el análisis rápido.
La Solución

Realicé la migración completa del sistema a Laravel 8, modernizando toda su arquitectura. Durante este proceso, no solo trasladé la funcionalidad existente, sino que resolví graves fallas de seguridad y elevé la calidad visual y documental:

Vista del módulo de Órdenes de Servicio con filtros avanzados y DataTables

Generación de PDFs

Implementé DomPDF para exportar los reportes que antes solo eran HTML sin formato, dándoles un diseño corporativo listo para imprimir.

Mejora Visual

Transformé tablas planas en DataTables con búsqueda, paginación, tooltips de ayuda y scroll horizontal sincronizado.

Validación SUNAT

Integré el consumo de una API externa para autocompletar RUC y Razón Social de proveedores en el formulario.
