Control de Presión Arterial
React Native · Node.js · Express · MySQL · Docker
El Reto

Desarrollar una aplicación móvil Full-Stack para el monitoreo de salud, dirigida a pacientes con hipertensión. El sistema debía ser capaz de:

  • Registro Clínico: Almacenar presión sistólica, diastólica, pulso y hábitos (café, estrés) para encontrar patrones.
  • Visualización de Datos: Gráficos interactivos de evolución y clasificación automática de riesgo (Normal, Elevada, Crisis).
  • Reportes Médicos: Exportar el historial a PDF y Excel para compartir con el doctor.
  • Seguridad: Autenticación segura y privacidad de los datos del paciente.
La Solución

Construí una arquitectura Cliente-Servidor separando el frontend móvil (React Native) del backend API (Node.js), comunicados mediante JWT.

Vistas principales: Historial con gráficos, Registro de medición y Dashboard del paciente.

Frontend (React Native)

Interfaz moderna con Expo Router, gráficos dinámicos con react-native-chart-kit y almacenamiento seguro de tokens con expo-secure-store.

Backend (Node.js)

API REST con Express, validaciones con Zod, autenticación JWT y contraseñas encriptadas con Bcrypt. Consultas SQL puras optimizadas.

Reportes PDF/Excel

El backend genera los documentos con PDFKit y ExcelJS, y el móvil los descarga usando expo-file-system y expo-sharing.

Lógica Médica SQL

Implementación de CTEs (Common Table Expressions) recursivas para generar fechas continuas en los gráficos, incluso si no hubo mediciones ese día.
