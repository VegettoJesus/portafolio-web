BeBranding
WordPress · Elementor · WP Super Cache · Smush · Contact Form 7
El Reto

Consiste en diseñar y desarrollar un sitio web completo para branding llamada BeBranding. Los objetivos eran:

  • Rendimiento: Las imágenes de alta resolución del portafolio hacían que la página cargara lento, por lo que se requería aplicar técnicas de optimización.
  • Diseño: Se requería una estética moderna, con carruseles interactivos y un flujo de contacto claro que reflejara la creatividad de la agencia.
  • Autogestión: Implementar un blog que se pudiera actualizar fácilmente sin tocar código.
La Solución

Construí el sitio web sobre WordPress, aplicando las mejores prácticas de maquetación, seguridad y optimización de rendimiento que aprendí en el curso.

Sección "Proceso de Branding" con maquetación personalizada.

Optimización de Velocidad

Configuré WP Super Cache para generar versiones estáticas, y Smush para comprimir imágenes sin perder calidad, logrando un tiempo de carga óptimo.

Galería Interactiva

Implementé WP Carousel para mostrar los diseños de packaging de forma dinámica y atractiva.

Formulario de Contacto

Desarrollé la sección de contacto con Contact Form 7, validando los datos del cliente para simular la captación de prospectos.

Child Theme & Admin

Creé un Child Theme para personalizar el CSS sin perder actualizaciones futuras. Además, estructuré las categorías del blog para facilitar el SEO.
