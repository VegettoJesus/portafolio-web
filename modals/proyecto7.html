E-Commerce Platform & Admin Panel
Laravel 8 · MySQL · Bootstrap 5 · jQuery · Arquitectura MVC
El Reto

Desarrollar un sistema de comercio electrónico "todo en uno" para una tienda de tecnología, con las siguientes complejidades:

  • Inventario Complejo: Manejar productos simples, con variaciones (talla/color) y agrupados, sin que el stock se descuadre.
  • Seguridad y Permisos: Diferentes roles (Admin, Vendedor, Cliente) con permisos granulares sobre cada menú y acción del sistema.
  • Flujo de Compra: Carrito que reserva stock real, cálculo dinámico de envíos y múltiples métodos de pago (Transferencia, QR, Contra entrega).
  • Auditoría: Registrar quién hizo qué, cuándo y desde qué IP.
La Solución

Construí un ecosistema robusto en Laravel, separando la lógica en Servicios, Traits de auditoría y Helpers de configuración.

Variaciones Cartesianas

Lógica avanzada para crear combinaciones automáticas de atributos (ej. Color: Rojo, Talla: M) generando SKUs, precios y stock individuales para cada variación.

Carrito con Reserva

Al agregar un producto al carrito, el sistema bloquea el stock temporalmente en base de datos para evitar sobreventas mientras el cliente finaliza la compra.

Sistema de Permisos

Menús dinámicos jerárquicos con permisos por rol (JSON) almacenados en caché por usuario. Validación estricta en cada controlador.

Auditoría Completa

Implementación de un Trait que registra cada acción (Crear, Editar, Eliminar) guardando valores anteriores, nuevos, IP y navegador para trazabilidad.
