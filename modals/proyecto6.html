Organix - Sistema de Gestión Agrícola
Java · MySQL · Arquitectura MVC & DAO
El Reto

Desarrollado como proyecto, el desafío consistió en crear un sistema de escritorio para una empresa agrícola ficticia "Organix" que necesitaba digitalizar la reserva de productos (frutas/verduras por toneladas), el control de stock y la facturación:

  • Procesos manuales: El registro de reservas y la validación de stock disponible eran propensos a errores humanos.
  • Roles de usuario: Se requería un sistema de autenticación claro que diferenciara entre Administrador (control total) y Cliente (solo sus reservas y pagos).
  • Generación documental: Las facturas debían generarse automáticamente calculando el peso total por el precio, sin intervención manual.
La Solución

Construí una aplicación de escritorio robusta desde cero, aplicando patrones de diseño de software para garantizar que el código fuera escalable y mantenible.

Pantalla de Login con validación de credenciales y roles de usuario

Panel de Administración: Gestión de stock y productos

Formulario de pedidos con validación de stock en tiempo real

Módulo de pago

Arquitectura MVC y DAO

Separé la lógica de negocio (Controladores), la interfaz gráfica (JFrame/Vistas) y el acceso a datos (Modelos y DAO), manteniendo las consultas SQL aisladas de la vista.

Control de Stock

Implementé la lógica para que, al crear un pedido, el sistema descuente automáticamente el stock y actualice la cantidad reservada, evitando sobreventas.

Seguridad y Roles

Validaciones lógicas para comprobar credenciales en MySQL antes de permitir el acceso, restringiendo vistas dependiendo del rol (Admin o Cliente).
